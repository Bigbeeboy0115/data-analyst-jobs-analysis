# 数据分析岗位招聘数据分析项目

项目定位：招聘市场数据分析项目  
分析主题：招聘岗位需求、城市分布、行业分布、技能要求与薪资关系

## 项目目标

本项目基于数据分析岗位招聘数据，完成数据清洗、探索性分析和可视化输出，回答以下问题：

- 数据分析岗位主要集中在哪些城市和行业？
- Python、SQL、Excel、Tableau 等技能的需求热度如何？
- 不同岗位类型、行业和技能组合对应的薪资水平有何差异？
- 数据分析岗位中哪些技能具有更高的需求频率和薪资相关性？

## 分析维度

- 城市岗位数量分布
- 行业岗位数量分布
- 薪资区间分布
- 技能需求热度
- 技能与薪资关系
- 岗位类别与薪资关系
- 技能价值矩阵

## 适合展示的能力

- Python 数据清洗
- Pandas 数据处理
- Matplotlib/Seaborn 可视化

- 数据分析结论整理

## 数据声明

本项目用于个人作品集展示和数据分析练习。若数据来自公开样例或历史招聘数据，分析结论仅代表样本本身，不代表实时招聘市场。
